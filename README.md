# 3D Web Experience

A Claude Code skill for planning and building performant, usable 3D experiences on the web.

## What it covers

- Three.js and React Three Fiber implementation
- WebGL and 3D performance optimization
- 3D model integration and GLB/GLTF workflows
- Spline-based scenes and workflows
- Interactive 3D scenes and product configurators
- Scroll-driven 3D interactions
- Mobile-friendly loading and fallback strategies

## Repository contents

| File | Purpose |
| --- | --- |
| `SKILL.md` | Complete skill instructions, implementation patterns, examples, and anti-patterns |
| `LICENSE` | License identifier for the included upstream skill |

## Usage

Use this skill in a Claude Code workflow when building a 3D website, interactive 3D scene, product configurator, 3D portfolio, or WebGL experience.

Keep the original `SKILL.md` in the location expected by your skill loader. Review its guidance before choosing a 3D stack or integrating 3D assets.

## Practical guidance

3D should improve the experience, not exist as decoration. Choose the lightest suitable approach, optimize assets, provide loading states, and test on mobile and lower-powered devices.
